Return one VisualEvidence JSON object. Record regional_observations first, then summarize overall form in object_observation. Use the supplied query view_id for each region.

- region gives only the physical part or surface position, such as "lower inner edge" or "upper-left surface". Leave out how you found it.
- query_evidence describes what is visible in the clean query for that view. Follow the object's own shape, color, texture and edges. An edge that appears only on the cue image is an overlay.
- normal_comparison compares the same physical part in the clean query and the listed normal reference. Align by visible landmarks. If pose, lighting or occlusion prevents comparison, state the limit. Another normal reference view can help.

In marked views, start with the physical area indicated by the cue and inspect it in the full clean query. Record a local fact about that area or what obscures it. Describe the surroundings separately. In unmarked views, inspect representative surfaces, edges and connections. Keep annotation graphics and coordinates out of the text. Report appearance and limits when material, contents or cause are unclear. Leave the defect judgment to Stage 2.

Keep distinct findings tied to the view where they are visible. Set visibility to clear, partial, or not_visible. In uncertainty, report the actual limitation or use JSON null when there is none.
